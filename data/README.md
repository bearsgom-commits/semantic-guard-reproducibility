# Dataset acquisition

The manuscript evaluation uses BEIR FiQA, SciFact and TREC-COVID.

**Dataset files are not bundled here at initialization.** Follow the original dataset provider's distribution and license terms; record download source, revision, corpus/query/qrels counts, hashes, and preprocessing decisions before claiming exact reproducibility.

No private documents, credentials, original unpublished corpora, or restricted evaluation materials should be committed.
